PYTHON COUNTDOWN TIMER

Files:
- countdown_timer.py: The countdown timer program.

Requirements:
- Python 3
- No third-party packages required.

Run:
1. Extract this ZIP file.
2. Open a terminal/command prompt in the extracted folder.
3. Run:
   python countdown_timer.py

On Windows, the program uses winsound.Beep. On macOS/Linux, it sends a terminal bell, which depends on terminal/system settings.
